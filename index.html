FAQ
ไม่พบพนักงานเมื่อสแกนบัตร? +
Admin ต้อง Import ข้อมูลพนักงานก่อน เมนู Admin → Import ข้อมูล
EMP กับ CW ต่างกันอย่างไร? +
EMP คือพนักงานประจำ, CW คือสัญญาจ้าง — จำแนกจาก Job Family keyword "Contingent"
ขึ้น "สแกนซ้ำ" หมายความว่าอะไร? +
พนักงานคนนั้นเคยสแกนบัตรไปแล้ว ระบบบันทึกเวลาล่าสุดทับ แต่ไม่ลบบันทึกแรก
Export เฉพาะวันนี้ได้ไหม? +
ได้ — ไปที่ "ประวัติ Check-in" ตั้งวันเริ่มและสิ้นสุดเป็นวันนี้ แล้วกด "Export ตามวันที่"
เมนูด้านล่าง Sidebar มองไม่เห็น? +
เลื่อน Scrollbar ด้านขวาของ Sidebar ลงได้ หรือกด Ctrl+\ เพื่อซ่อน/แสดง Sidebar เพื่อเพิ่มพื้นที่
