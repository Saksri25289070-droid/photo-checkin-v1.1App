📷 Photo Check-in System
ระบบเช็คอินพนักงานด้วยบัตร RFID สำหรับโรงงาน PRB และ BPI
รองรับพนักงานประจำ (EMP) และพนักงานสัญญาจ้าง (CW) · บันทึกข้อมูลแบบ Realtime
วิธีเช็คอินพนักงาน
1
คลิกเมนู "สแกนบัตร" ในแถบซ้าย
หน้าสแกนบัตรจะเปิดขึ้น มีช่องป้อนข้อมูลตรงกลางหน้าจอ
2
แตะบัตร RFID ที่เครื่องอ่านบัตร
เครื่องอ่านบัตรจะส่งรหัสเข้าช่องโดยอัตโนมัติ หรือพิมพ์ Badge ID / Employee ID ด้วยตนเอง แล้วกด Enter
💡 รองรับทั้ง Badge ID และ Employee ID
3
ระบบแสดงข้อมูลพนักงานและบันทึกเวลา
ข้อมูลชื่อ แผนก Site และเวลาจะแสดงขึ้น พร้อมเสียงแจ้งเตือนและบันทึกอัตโนมัติ
✅ สแกนซ้ำได้ — ระบบบันทึกทับและแจ้งว่า "สแกนซ้ำ"
ความหมายของสถานะต่าง ๆ
✅ เช็คอินสำเร็จ
พบข้อมูลในระบบ บันทึกเวลาเรียบร้อย มีเสียง "ติ๊ง" 4 ครั้ง
🔁 สแกนซ้ำ
เช็คอินซ้ำในวันเดิม ระบบบันทึกทับ มีเสียงเตือน 3 ครั้ง
⚠ ไม่พบข้อมูล
ไม่พบรหัสนี้ในฐานข้อมูล กรุณาตรวจสอบรหัสบัตร
🏷 CW Badge

คำถามที่พบบ่อย (FAQ)
❓ สแกนบัตรแล้วขึ้น "ไม่พบข้อมูล" ทำอย่างไร?
ตรวจสอบว่า Badge ID หรือ Employee ID ที่สแกนตรงกับข้อมูลในระบบหรือไม่
ถ้าเป็นพนักงานใหม่ ให้ Admin Import ข้อมูลก่อนหรือเพิ่มด้วยมือที่เมนู "เพิ่มพนักงาน"
❓ ข้อมูลจะถูกรีเซ็ตทุกวันหรือไม่?
หน้าสแกนและสรุปจะแสดงเฉพาะ วันปัจจุบัน เท่านั้น
แต่ประวัติ Check-in ยังคงอยู่ในระบบ สามารถ Export ย้อนหลังได้ที่เมนู "ประวัติ Check-in"
❓ ความแตกต่างระหว่าง EMP และ CW คืออะไร?
EMP = พนักงานประจำ Western Digital
CW = Contingent Worker (พนักงานสัญญาจ้าง/outsource)
สังเกตได้จากป้าย CW สีส้ม ที่แสดงบนบัตร
❓ ถ้าสแกนบัตรผิดคน จะลบออกได้ไหม?
Admin สามารถลบรายการ Check-in ได้ที่เมนู "ประวัติ Check-in" → กดปุ่ม "ลบ" ที่แถวนั้น ๆ
User ทั่วไปไม่สามารถลบได้
❓ Admin จะเพิ่ม User ใหม่ได้อย่างไร?
ไปที่เมนู Admin → จัดการ User → กดปุ่ม "เพิ่ม User ใหม่"
กรอก Email + Password + Role → กด "สร้าง User" — ระบบจะสร้างบัญชีให้อัตโนมัติ
ℹ️
ข้อมูลทั้งหมดบันทึกแบบ Realtime ทุกหน้าจะอัปเดตโดยอัตโนมัติ ไม่ต้อง Refresh หน้า
⚠️
การลบข้อมูลไม่สามารถกู้คืนได้ กรุณาตรวจสอบก่อนยืนยัน — เฉพาะ Admin เท่านั้น
✅
ระบบรองรับทั้ง PRB และ BPI ในหน้าเดียว สามารถ Export แยก Site ได้จากเมนูสรุปจำนวน
